先把H743IIT6_16M.FLM文件拷贝进keil\ARM\Flash文件夹，再在工程设置里把它添加进来，否则无法烧写外部Flash。另外还需把RAM for Algorithm的Size由0x00008000改成0x0000F000，太小也会下载失败

First copy the H743IIT6_16M.FLM file into the keil\ARM\Flash folder, and then add it in the project settings, otherwise you can't burn the external Flash. in addition, you also need to change the Size of the RAM for Algorithm from 0x00008000 to 0x0000F000, it's too small, it will also be a failure to download.
